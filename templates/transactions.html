ROLLBACK transaction

Starts the same insert, then cancels it. The event should not remain in the database.

How to explain it in your viva

  • Transaction: a group of database operations treated as one unit.
  • COMMIT: makes the transaction's changes permanent.
  • ROLLBACK: cancels uncommitted changes if an operation fails or should be undone.
  • ACID: Atomicity, Consistency, Isolation and Durability are key transaction properties.
